# Python-File-Handling-Project

A simple, interactive command-line application that demonstrates fundamental file operations in Python. This project allows users to create, read, append, delete, and analyze text files directly from the terminal.

## ✨ Features

* **Create:** Generate new text files with initial content.
* **Read:** Display the contents of an existing file.
* **Append:** Add new text to the end of an existing file without overwriting it.
* **Delete:** Safely remove files from the directory.
* **Error Handling:** Built-in safeguards for common issues like `FileNotFoundError` and permission restrictions.

## 🛠️ Prerequisites

* Python 3.x installed on your system.
* No external libraries required (uses Python's built-in `os` and `sys` modules).
